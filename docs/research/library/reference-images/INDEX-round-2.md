# Reference images, round two

Checked: 2026-11-17.

These pictures are only for looking and comparing. They are not to be traced, copied into a repository, or shipped with the engine. Placement is Claude's job; nothing here was pushed anywhere.

> **Note added when this set was published (2026-11-17).** The sentence above is the brief the set was
> gathered under. Specula's owner had the pictures published in this repository, which every picture's
> licence allows. What stands: they are looked at and compared, never traced, and no picture's pixels go
> into an asset or ship with the engine. Changed from the delivery: seven Muybridge plates of men in
> loincloths are under `ADULTS-ONLY/4-motion/` here (their paths below say so), so the counts in the
> table below read 37 for `4-motion` and 20 for `ADULTS-ONLY/4-motion` in this repository.
>
> **Two pictures of the delivery are not in this repository**, and nothing of them is kept here, not
> their rows and not their links (159 pictures of this set are here, not 161): a chart of body
> proportions by age whose figures were children drawn without clothes, and a drawing of two unclothed
> young women whose age nothing showed. This repository holds no unclothed figure of a child, drawn or
> photographed, and none whose subject cannot be shown to be an adult. A row of the list of links
> below that pointed at such a figure is taken out as well.

The brief for this round is Claude's `docs/research/REFERENCE_ROUND2_BRIEF.md`. The file itself did not reach the box or the Mac and is not public, so this set follows the brief as relayed in the request (parts 1 to 4; part 5 skipped). Rules followed: public domain and CC0 first, then CC BY and CC BY-SA with the author named; anything else is a link only and was not downloaded; licences were read from the Commons API (`prop=imageinfo&iiprop=url|size|extmetadata`), never guessed; nothing from round one (`specula-imagines`) is repeated.

Folder layout matches round one: `1-whole-body`, `2-weak-areas`, `3-head`, `4-motion`, `5-creatures`, plus a new `6-2d`. Unclothed figures and plates sit under `ADULTS-ONLY/` with the same sub-folders. Muybridge plates of children were left out entirely.

Size rule: the long side is capped at Commons' own render. Commons now serves thumbnails only at standard widths (1,280, 1,920, 2,560 px and so on), so each file is the largest standard render whose long side is at most 2,500 px, or the original when that is smaller. Book pages inside DjVu files (Stratz 1898) were rendered by Commons at 1,280 px wide. The pixel size in each row is the file actually saved. Four 2D items are below 1,500 px because no larger open version exists; that is noted in their rows.

Separators: in the source and licence cells, `·` separates the link from the author or licence name.
