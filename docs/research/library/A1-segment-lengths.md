## Table A1-2. ANSUR II derived "link" dimensions (✔ read directly; the report defines each by subtraction)

Definitions (in my words, from the report): Thigh link = trochanterion height − lateral femoral epicondyle height. Calf link = lateral femoral epicondyle height − lateral malleolus height. Neck link = stature − tragion-to-top-of-head − cervicale height (cervicale to tragion, vertical). Thorax link = cervicale height − tenth-rib height. Abdominal link = tenth-rib height − iliocristale height. Pelvic link = iliocristale height − trochanterion height. Clavicle link = ½ biacromial breadth. Elbow–wrist length = forearm–hand length − hand length. Arm length = acromial height − wrist height + hand length.

## Sources disagree

- **Thigh**: Drillis–Contini 0.245H vs ANSUR II thigh link 0.233H (both sexes) vs de Leva hip-joint-centre to knee-joint-centre 0.212H (F) / 0.243H (M). The landmarks differ: trochanterion is not the hip joint centre (de Leva puts the joint centre slightly above it). The F/M difference in de Leva comes from the small (n = 15) female sample.
- **Shank**: Drillis 0.246H vs ANSUR calf link 0.248H (F) / 0.238H (M) vs de Leva 0.249H. They broadly agree.
- **Upper arm**: Drillis 0.186H vs ANSUR acromion–radiale 0.191H vs de Leva joint-centre 0.159–0.162H. de Leva measures from the shoulder joint centre, which lies well below the acromion.
- **Shoulder width**: Drillis 0.259H falls between ANSUR biacromial (bone, 0.224/0.237) and bideltoid (flesh, 0.277/0.291), so its landmark is ambiguous.
- **Hip width**: Drillis 0.191H vs ANSUR hip breadth 0.217 (F) / 0.197 (M). Drillis has no sex split, and women are relatively wider.
- **Foot**: Drillis 0.152H vs ANSUR 0.151 (F) / 0.154 (M), which agree; de Leva heel–toe 0.132 (F) is lower (small sample).
