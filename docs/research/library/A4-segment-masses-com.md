## Sources disagree

- **Thigh mass**: de Leva 14.16 % (M) / 14.78 % (F) vs Dempster 9.6–9.7 %. That is a large gap. Likely causes are elderly, lean cadavers vs young athletes, and different boundary planes between thigh and trunk. The plane definitions were not compared line by line in this pass, so treat that explanation as unverified.
- **Trunk**: Dempster splits off "shoulders" (10.3 %), so his thorax is only 11.0 %. de Leva's whole trunk (42.6–43.5 %) includes the shoulder girdle. They cannot be compared row for row.
- **Head**: de Leva 6.9 % (M) vs Dempster head+neck 7.9 %. The neck is assigned differently.
- **Upper-arm CM**: de Leva 57.7 % from the shoulder joint centre vs Dempster 43.6 % from the gleno-humeral axis. Dempster's figure is closer to proximal. Reference points and populations both differ.
- **Hand CM**: Dempster 50.6 % (wrist to knuckle III) vs de Leva 79.0 % (wrist JC to MET3) or 36.2 % (to fingertip). The endpoint definitions differ, so match the endpoints before using either.
