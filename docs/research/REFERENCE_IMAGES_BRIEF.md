# Reference images: what is asked for

Status: **answered the same day: 110 pictures, indexed in
[library/reference-images/](library/reference-images/README.md).** What follows is the request as it was
written. The owner offered reference pictures to hold the engine's
figures against ("Reference images.. sure. I'll get you those. Please get me a list of what you need").
This is the list. It goes beside the library research ([library/](library/README.md)), which gave the
numbers; these give something to look at.

## Why

The figures of M6 part 4 are built from measurements, and everything between the measured places is the
builder's judgement, checked by looking at the engine's own captures. A fault is recognised once it is
seen; without a picture of the real thing beside it, "does this look right" rests on one model's eye.
Seven versions of the first figure were made in a day that way (`gallery-full/part4/figure/NOTES.md`,
on the development machine): a reference would have shortened it.

## How they are used

- **Looked at and compared, nothing more.** A reference and a capture are put side by side at one
  scale, and the differences in outline and proportion are written down. Nothing is traced, no picture's
  pixels go into an asset, and none is copied into this repository.
- They are kept in a folder outside the repository (beside the research's delivery folder), unless a
  picture's licence plainly allows keeping it and there is a reason to.

## What each picture needs to come with

One index file (Markdown or CSV) in the folder, a row a picture:

| Field | |
|---|---|
| file | the file's name in the folder |
| shows | what it is: "adult woman, average build, standing, front" |
| view | front, side (which), back, three-quarter, top, sole, and so on |
| subject | sex, rough age, build; **the height if it is known**, or a scale in the picture |
| source | the page it came from (a link), the author or the collection, the year |
| licence | public domain, CC0, CC BY, CC BY-SA, with the link that says so |
| checked | the date the link and the licence were looked at |

**Rights.** Public domain and CC0 first (old anatomical plates and Muybridge's photographs are). CC BY
and CC BY-SA are fine, with the author listed. Anything else (non-commercial, no-derivatives, all rights
reserved): send the link in the index and not the file, marked as such.

**The pictures themselves.**

- The whole subject in the frame, on a plain background, taken from far enough that it is not distorted
  (as near to a flat, straight-on view as there is).
- At least 1,500 pixels on the long side.
- For people: standing straight, arms a little away from the sides or hanging, feet visible; close-fitting
  clothes or an anatomical plate, either is fine. Adults only. Nothing sexual.
- The same subject in several views is worth more than several subjects in one view each.
- Three to six pictures a row below is plenty. A consistent set beats a large one.
